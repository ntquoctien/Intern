3. CẤU HÌNH MÔI TRƯỜNG (.ENV & USER SECRETS)
-------------------------------------------------------------------------------
A. Tệp .env cho VectorMatchService (Python AI Service):
   - Đường dẫn: EducationSystem\src\Services\VectorMatchService\.env
   - Nội dung mẫu:
     VECTOR_ACADEMIC_DB_CONNECTION_STRING=
     VECTOR_CAREER_DB_CONNECTION_STRING=
     VECTOR_MODEL_NAME=sentence-transformers/multi-qa-MiniLM-L6-cos-v1
     VECTOR_MODEL_DEVICE=cpu
     VECTOR_ELIGIBLE_GPA_THRESHOLD=7.0
     VECTOR_INDEX_TTL_SECONDS=900
     VECTOR_INTERNAL_API_KEY=

B. User Secrets cho các dịch vụ .NET (Tùy chọn thiết lập nâng cao):
   - Cài đặt LLM API Key cho CareerService (Groq / Gemini 3.5 Flash):
     cd EducationSystem
     dotnet user-secrets set "LLM:Provider" "Groq" --project .\src\Services\CareerService\CareerService.csproj
     dotnet user-secrets set "LLM:Model" "qwen/qwen3.5-27b" --project .\src\Services\CareerService\CareerService.csproj
     dotnet user-secrets set "LLM:ApiKey" "<GROQ_API_KEY_CỦA_BẠN>" --project .\src\Services\CareerService\CareerService.csproj
     dotnet user-secrets set "Gemini:ApiKey" "<GEMINI_3.5_FLASH_API_KEY_CỦA_BẠN>" --project .\src\Services\CareerService\CareerService.csproj

   - Cài đặt Gmail SMTP cho CommunicationService (Gửi Email thực tập):
     dotnet user-secrets set "InternshipEmail:SmtpHost" "smtp.gmail.com" --project .\src\Services\CommunicationService\CommunicationService.csproj
     dotnet user-secrets set "InternshipEmail:SmtpPort" "587" --project .\src\Services\CommunicationService\CommunicationService.csproj
     dotnet user-secrets set "InternshipEmail:Username" "email_cua_ban@gmail.com" --project .\src\Services\CommunicationService\CommunicationService.csproj

4. SCRIPT KHỞI CHẠY HỆ THỐNG FULL
-------------------------------------------------------------------------------
Mở cửa sổ PowerShell và di chuyển vào thư mục EducationSystem:

   cd D:\Intern_IT\Intern\EducationSystem

A. Lệnh khởi chạy TOÀN BỘ Hệ thống (Backend + Frontend):
   
   .\scripts\Start-Dev.ps1

B. Lệnh chỉ khởi chạy các dịch vụ Backend (.NET Microservices):

   .\scripts\Start-BackendServices.ps1

C. Lệnh tắt toàn bộ các dịch vụ Backend đang chạy:

   .\scripts\Stop-BackendServices.ps1

6. XỬ LÝ LỖI THƯỜNG GẶP (TROUBLESHOOTING)
-------------------------------------------------------------------------------
- Lỗi không mở được CSDL (Error 26 / Error 40):
  + Kiểm tra tên SQL Server Instance trong connectionstrings.Development.json đã đúng tên máy chưa.
  + Kiểm tra dịch vụ SQL Server (MSSQLSERVER/SOFTWAREINTERN) trong Windows Services đã Started chưa.

- Lỗi Port in use (Cổng bị chiếm dụng):
  + Chạy lệnh .\scripts\Stop-BackendServices.ps1 để giải phóng cổng.
